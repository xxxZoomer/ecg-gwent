# ecg-gwent

ECG波形をモチーフにした、CPU対戦型のシングルプレイカードゲームです。心電図所見付きの不整脈・虚血・伝導障害・電解質異常カードを使い、先に2ラウンド獲得すると勝利するベスト・オブ・3形式で対戦します。

## 起動

```bash
npm install
npm run dev
```

本番ビルドは `npm run build`、ビルド結果の確認は `npm run preview` です。

## 遊び方

- 手札からカードを選択して「プレイする」と、パワーが盤面スコアに加算されます。カードには疾患名と代表的なECG所見が表示されます。
- CPUは自動でカードをプレイまたはパスします。両者がパスすると高得点側がラウンドを獲得し、同点は引き分けです。
- 先に2ラウンド獲得すると試合終了です。最大3ラウンドを戦い、最後まで同点の場合は引き分けになります。次ラウンドには残った手札を持ち越し、3枚引きます。
- 右上のリセットボタンからいつでも新しい試合を始められます。

## ファイル

- `index.html`: アプリの HTML エントリーポイントとメタデータ。
- `package.json`: 起動・ビルドスクリプトと依存パッケージ。
- `package-lock.json`: npm 依存関係の再現可能なバージョンロック。
- `.gitignore`: 依存関係とビルド生成物を Git の追跡対象から除外。
- `vite.config.ts`: React と Tailwind CSS の Vite プラグイン設定。
- `tsconfig.json`: TypeScript の厳格な型検査と JSON import 設定。
- `src/main.tsx`: React アプリのマウントとグローバル CSS の読み込み。
- `src/App.tsx`: 対戦画面、手札操作、スコアボード、結果画面。
- `src/Card.tsx`: ECG 波形、カード情報、選択状態を描画する再利用コンポーネント。
- `src/GameBoard.tsx`: CPU とプレイヤーの盤面、各盤面スコアを描画するコンポーネント。
- `src/game.ts`: シャッフル、カードプレイ、CPUの手番、ラウンドと勝敗の処理。
- `src/data/cards.json`: 15種類の疾患カード名・パワー・ECG所見・波形データ。
- `src/styles.css`: Tailwind CSS とレスポンシブなゲーム画面のスタイル。
